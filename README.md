# Interactive Periodic Table

A visually engaging and searchable interactive periodic table built using **HTML**, **CSS**, and **JavaScript**.

## Features

- 🔍 **Search Functionality**  
  Search elements by atomic number, symbol, or name.

- 🧪 **Hover Popup**  
  Displays quick information such as element name, symbol, atomic number, and category.

- 📖 **Detailed Element View**  
  Click on an element to view detailed information including atomic mass, electronegativity, and more.

- 🎨 **Color-Coded Categories**  
  Different element categories are visually distinguished for better understanding and user experience.


## Usage

1. Clone the repository:

```bash
git clone https://github.com/SameerSingh017/periodic_table.git
```

2. Navigate to the project folder:

```bash
cd periodic_table
```

3. Open `index.html` in any modern web browser.
